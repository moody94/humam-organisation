# MEAL Bridge GitHub Pages website

This folder contains the static version of the approved MEAL Bridge redesign.

## Main pages

- `index.html` — Home
- `services.html` — Solutions
- `academy.html` — Academy
- `about.html` — About
- `contact.html` — Contact

## Manual image replacement

Replace files inside `assets/images/` while keeping the same filename and extension:

- `evidence-to-impact.webp` — Home hero and Solutions page image
- `meal-ecosystem.webp` — Home evidence-to-impact diagram
- `humam-alherk.webp` — About founder image
- `meal-bridge-logo.png` — Header logo

The contact form sends to the existing Formspree endpoint. Test it after the final domain is connected.

The package intentionally does not contain a `CNAME` file yet. Add the custom domain only after the temporary GitHub Pages address has been tested.
